Политика конфиденциальности

Приложение «Панель канала», обновлено 2 ноября 2026 года. Приложение личное: им пользуется только его владелец, музыкант Евгений Анненков, для своего канала @Annenkof23.

Какие данные используются

Через YouTube API Services приложение получает данные только этого канала: список видео, названия, описания, теги, просмотры, лайки, число подписчиков и сводную статистику YouTube Analytics. Персональные данные зрителей приложение не собирает.

Зачем они нужны

Чтобы загружать видео владельца по расписанию, показывать ему статистику и обновлять названия и теги его видео.

Где хранятся данные и кому передаются

Данные и ключ доступа Google хранятся на компьютере владельца. Сводки по каналу отправляются самому владельцу через его бот в Telegram. Для анализа статистики и подготовки отчётов данные канала обрабатывает ИИ-помощник Claude компании Anthropic. Больше никому данные не передаются и не продаются.

Как отключить доступ

Доступ приложения можно отозвать в любой момент на странице настроек доступа Google. Сохранённые данные удаляются с компьютера владельца вместе с папкой приложения.

Правила YouTube и Google

Приложение использует YouTube API Services. Действуют Условия использования YouTube и Политика конфиденциальности Google.

Контакты

Связаться с владельцем можно через канал на YouTube.

Summary (English)

This personal app uses YouTube API Services to access data of one channel only, @Annenkof23: videos, metadata, public counts and aggregated YouTube Analytics. It collects no viewer personal data. Data and the Google access token stay on the owner's computer. Channel summaries are sent to the owner through his Telegram bot, and channel data is processed by the AI assistant Claude by Anthropic for analytics reports. Data is not sold or shared with anyone else. Access can be revoked at Google permissions. See the YouTube Terms of Service and the Google Privacy Policy.
